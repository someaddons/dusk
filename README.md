# Dusk

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_468908_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/468908.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Dusk is a Minecraft mod which gives you full control over how dangerous Minecraft nights become.

- Control when players are allowed to sleep and skip the night
- Optionally disable sleeping entirely
- Increase monster spawns at night, gradually ramping up until midnight
- Set the global monster cap, increasing the total amount of hostile mobs in the world
- New in 4.1+: Adjust hostile mob spawn light requirements during the night
- New in 4.1+: Make hostile mobs detect players from farther away at night
- New in 4.1+: Give hostile mobs configurable potion blessings during the night

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.
